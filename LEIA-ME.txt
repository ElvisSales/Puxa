PUXA — BAIXADOR INSTA & FACE
=====================

COMO INSTALAR (uma vez só)
1. Instale o Python 3.10 ou mais novo: https://www.python.org/downloads/
   (no Windows, marque "Add Python to PATH" na instalação)
2. Abra o terminal (Prompt de Comando) dentro desta pasta e rode:
      pip install -r requirements.txt
3. (Opcional, recomendado) Instale o ffmpeg para vídeos com melhor qualidade e áudio:
      Windows:  winget install ffmpeg
      Mac:      brew install ffmpeg

COMO USAR
1. Na pasta, rode:   python app.py
2. Abra no navegador:   http://localhost:5000
3. Cole o link, escolha Instagram/Facebook e Imagem/Vídeo, clique em Baixar.
   - O site já tenta detectar a rede e se é vídeo sozinho ao colar o link.
   - Carrossel com várias fotos/vídeos vem num arquivo .zip.

SE DER ERRO DE "EXIGE LOGIN"
O Instagram e o Facebook bloqueiam muitos downloads sem estar logado.
1. Instale no Chrome a extensão "Get cookies.txt LOCALLY".
2. Entre no instagram.com (e/ou facebook.com) logado, clique na extensão e exporte.
3. Salve o arquivo como  cookies.txt  dentro desta pasta e reinicie o app.
   Guarde esse arquivo só com você: ele dá acesso à sua conta.

SE PARAR DE FUNCIONAR
As redes mudam com frequência. Atualize as ferramentas:
      pip install -U yt-dlp gallery-dl

Baixe apenas conteúdo seu ou que você tenha permissão para usar.

ANÚNCIOS
1. Crie conta numa rede de anúncios (ex.: Adsterra ou Monetag) e cadastre seu site.
2. Gere um banner 300x250 e copie o código que eles dão.
3. Abra templates/anuncio.html, cole o código no lugar do comentário e salve.
4. Suba o arquivo no GitHub (Add file > Upload files > Commit). O Render atualiza sozinho.
Para ver a tela de anúncio antes de ter o código: abra o site com ?anuncio no final.
Para mudar o tempo até liberar o X: em templates/index.html, SEGUNDOS_ANUNCIO = 5.
